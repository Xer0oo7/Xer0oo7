## `01` — ABOUT

I'm a **Computer Science student and developer** who enjoys turning ideas into working software.

I've explored web development, backend engineering, and software systems, but my current rabbit hole is **AI engineering** — particularly the systems around LLMs rather than just the models themselves.

I'm interested in how agents **reason, use tools, retrieve information, remember context, and work together**.
